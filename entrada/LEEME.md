# Correos de entrada

Deja aquí los correos como archivos `.eml` (en Gmail: abre el correo, menú de los tres puntos, "Descargar mensaje").

Después, en la raíz del proyecto:

    npm run redaccion

Esta carpeta no se sube a GitHub: solo se guarda este archivo. El registro de lo ya procesado está en `procesados.json`.
